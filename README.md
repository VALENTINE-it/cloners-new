# HACKER NEWS VANGUARD

A high-performance, framework-free web reader for Hacker News built with vanilla JavaScript (ES6 Modules), HTML5, and CSS3.

- **Chris Owila**: `src/js/features/comments.js`, `src/js/features/pagination.js`, `src/js/utils/debounce.js`, `src/js/utils/time.js`
- **Joe Beckham**: `src/js/ui/feed.js`, `src/js/ui/comments.js`, `src/js/ui/liveBanner.js`, `src/js/ui/render.js`, `src/data/livePoller.js`, `index.html`

python3 -m http.server 8080
